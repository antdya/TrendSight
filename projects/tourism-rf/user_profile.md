# Анкета пользователя — tourism-rf

> Файл читается промтом 01 на каждом запуске. Редактировать вручную.

```yaml
goal: Для принятия стратегических решений
audience: Я + внутренняя команда
news_type: Только факты и события
period: Последние 7 дней
volume: 10-15 новостей максимального приоритета
why_important: Да, обязательно
source_reliability: Можно включать ранние сигналы, даже если это слабый сигнал
themes: Туризм
geography: Россия
importance:
  - Влияет на спрос / выручку
  - Дает продуктовые идеи
  - Дает инвестиционные сигналы
  - Меняет правила игры на рынке
  - Прочие новости участников рынка
exclude: Повторы и пересказы
format: Расширенно — мини-анализ по каждой новости + таблица
actions_block:
  - Да: что проверить
  - Да: какие возможности/риски появились
sources: Только источники по России — локальные СМИ, консалтинг, исследования и отчёты, корпоративные пресс-релизы крупных игроков
output_format: Markdown (для записи в GitHub)
```
