# Анкета пользователя — wellness

> Файл читается промтом 01 на каждом запуске. Заполните и сохраните.

```yaml
goal: Стратегические решения
audience: Команда
news_type: Факты + мнения экспертов
period: Последние 7 дней
volume: 10-15 новостей максимального приоритета
why_important: Да, обязательно
source_reliability: Можно включать ранние сигналы
themes: здоровье, wellness
geography: Россия
importance:
  - Влияет на спрос / выручку
  - Дает продуктовые идеи
  - Дает инвестиционные сигналы
  - Меняет правила игры на рынке
  - Изменения в регулировании
  - Действия конкурентов
exclude: Повторы и пересказы
format: Расширенно — мини-анализ по каждой новости + таблица
actions_block:
  - Да: что проверить
  - Да: какие возможности/риски появились
sources: # Описание приоритетных источников
output_format: Markdown (для записи в GitHub)
notes: # Любые дополнительные параметры
```
