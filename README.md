# Инструкция по работе
Для получения дайджеста используйте свою llm с версией, которая может работать напрямую с github (подключаться к вашему аккаунту на github, читать данные из репозитория и **записывать**).

## Подключение аккаунта github в вашей llm
1. Убедитесь, что вы получили доступ к репозиторию https://github.com/antdya/TrendSight.
2. Если вы ранее не использовали коннектор github в своем аккаунте llm - подключите его (обычно, это доступно только в платных версиях).


## Получение дайджеста
Если проект уже был создан ранее, для получения очередного дайжеста в новом чате llm выполните следующий промпт:
```
REPO: https://github.com/antdya/TrendSight
PROJECT: {укажите название вашего проекта, напр., new-hotel}
WEEk: {укажите номер недели для получения дайджеста}
Выполни step-1.md
```
После выполнения llm-кой промпта следуйте инструкциям (выполняйте step-2 и step-3)

Важно!<br>
при отправке промтов убедитесь, что у вас в чате llm активирован коннектор github (иначе llm не сможет читать и записывать данные в github и ничего не будет работать).


## Создание нового проекта для получения дайджеста
Если вы используете данный помощник по новой теме (не использовали ранее) - сначала создайте новый проект.<br>
Для этого в новом чате llm выполните следующий промпт:
```
Репозиторий: https://github.com/antdya/TrendSight
Выполни step-0.md
```
