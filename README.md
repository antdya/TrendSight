# TrendSight MVP

> **Цель:** проверить гипотезу продукта без разработки — запуская промт в Perplexity раз в неделю.

## Что это

Бездевелопментный MVP: Perplexity (или любой LLM с web-search) запускается по расписанию, получает анкету пользователя, собирает отраслевые сигналы, дедуплицирует, приоритизирует и записывает дайджест в этот репозиторий. Следующий запуск читает историю из репозитория и строит аналитику по трендам.

## Структура репозитория

```
TrendSight/
├── README.md                    ← этот файл
├── config/
│   ├── user_profile.md          ← анкета пользователя (редактировать вручную)
│   └── product_brief.md         ← описание продукта команды
├── prompts/
│   ├── 01_collect.md            ← промт: сбор + дедуп + приоритизация
│   ├── 02_analyze.md            ← промт: аналитика трендов по истории
│   └── 03_brief.md              ← промт: финальный бриф для команды
├── digests/
│   └── YYYY-WNN/
│       ├── raw_digest.md        ← результат промта 01
│       └── analysis.md          ← результат промтов 02 + 03
└── memory/
    └── signal_log.md            ← накопленный лог сигналов по неделям
```

См. подробное описание: [prompts/README.md](prompts/README.md)

## Гипотезы, которые проверяет MVP

1. Perplexity с web-search покрывает ≥80% релевантных открытых источников по вертикали «Туризм / РФ».
2. Недельный дайджест из 10-15 сигналов даёт команде actionable инсайты без ручного мониторинга.
3. Накопленная история (signal_log) позволяет выявлять тренды и проверять ранее выдвинутые гипотезы.
4. Формат «что произошло / почему важно / что проверить» воспринимается командой как достаточный для принятия решений.
