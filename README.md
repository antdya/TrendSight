# TrendSight MVP

> **Цель:** проверить гипотезу продукта без разработки — запуская промт в Perplexity раз в неделю.

## Структура репозитория

```
TrendSight/
├── README.md
├── prompts/                        ← общие промты для всех продуктов
│   ├── README.md                   ← инструкция по запуску
│   ├── 01_collect.md
│   ├── 02_analyze.md
│   └── 03_brief.md
└── projects/
    ├── tourism-rf/                 ← продукт 1: туризм РФ
    │   ├── user_profile.md         ← анкета пользователя
    │   ├── product_brief.md        ← описание продукта + гипотезы
    │   ├── digests/
    │   │   └── YYYY-WNN/
    │   │       ├── raw_digest.md
    │   │       └── analysis.md
    │   └── memory/
    │       └── signal_log.md
    └── _template/                  ← шаблон для нового продукта
        ├── user_profile.md
        ├── product_brief.md
        ├── digests/.gitkeep
        └── memory/
            └── signal_log.md
```

## Как добавить новый продукт

1. Скопировать папку `projects/_template/` → переименовать (напр. `realestate-rf`).
2. Заполнить `user_profile.md` и `product_brief.md`.
3. Запускать промты из `prompts/`, подставляя данные нужного продукта.

## Как запускать

См. [prompts/README.md](prompts/README.md)

## Гипотезы, которые проверяет MVP

1. Perplexity с web-search покрывает ≥80% релевантных открытых источников по вертикали.
2. Еженедельный дайджест из 10-15 сигналов даёт команде actionable инсайты без ручного мониторинга.
3. Накопленная история (signal_log) позволяет выявлять тренды и проверять ранее выдвинутые гипотезы.
4. Формат «что произошло / почему важно / что проверить» воспринимается командой как достаточный для принятия решений.
