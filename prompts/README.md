# Как запускать MVP

## Инструмент

[Perplexity AI](https://www.perplexity.ai) — режим **Research** (или любой LLM с поиском: ChatGPT + web search, Claude + web search).

Perplexity подходит лучше всего: он сам ищет источники в реальном времени, поэтому не нужно указывать конкретные URL — достаточно описать типы источников.

## Расписание

Каждую **пятницу** (или любой выбранный день недели), 1 раз в 7 дней.

## Порядок запуска (3 шага)

### Шаг 1 — Сбор дайджеста

1. Открыть файл `config/user_profile.md` — скопировать содержимое.
2. Открыть файл `prompts/01_collect.md` — скопировать промт.
3. Вставить в Perplexity: сначала содержимое анкеты, затем промт.
4. Получить ответ → сохранить как `digests/YYYY-WNN/raw_digest.md`.

### Шаг 2 — Аналитика трендов

1. Открыть `memory/signal_log.md` — скопировать последние 4-8 недель.
2. Открыть `config/product_brief.md` — скопировать.
3. Открыть `prompts/02_analyze.md` — скопировать промт.
4. Вставить в Perplexity: signal_log + product_brief + промт.
5. Получить ответ → добавить в `digests/YYYY-WNN/analysis.md`.

### Шаг 3 — Бриф для команды

1. Открыть `prompts/03_brief.md`.
2. Вставить в Perplexity: raw_digest + analysis + промт.
3. Получить финальный бриф → дополнить `digests/YYYY-WNN/analysis.md` или отправить в Telegram/Slack.

### Шаг 4 — Обновить memory

1. Открыть `memory/signal_log.md`.
2. Добавить строку с топ-5 сигналами этой недели (см. формат в файле).
3. Сохранить в репозиторий.

## Время на сессию

| Шаг | Ручная работа | Ожидание LLM |
|-----|--------------|---------------|
| Шаг 1 | ~3 мин | ~2-5 мин |
| Шаг 2 | ~5 мин | ~2-5 мин |
| Шаг 3 | ~3 мин | ~1-3 мин |
| Шаг 4 | ~5 мин | — |
| **Итого** | **~16 мин/нед** | — |

## Что записывать в репозиторий

- `digests/YYYY-WNN/raw_digest.md` — сырой дайджест из шага 1
- `digests/YYYY-WNN/analysis.md` — аналитика + финальный бриф
- `memory/signal_log.md` — обновлённый лог (добавлять, не перезаписывать)
