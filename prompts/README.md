# Как запускать MVP

## Инструмент

[Perplexity AI](https://www.perplexity.ai) — режим **Research** (или любой LLM с web-search: ChatGPT, Claude).

## Расписание

Каждую **пятницу** (или любой выбранный день), 1 раз в 7 дней. Суммарно ~16 минут ручной работы.

## Порядок запуска (4 шага)

### Шаг 1 — Сбор дайджеста

1. Открыть `projects/{product}/user_profile.md` → скопировать содержимое.
2. Открыть `prompts/01_collect.md` → скопировать промт.
3. Вставить в Perplexity: сначала содержимое анкеты, затем промт.
4. Получить ответ → сохранить как `projects/{product}/digests/YYYY-WNN/raw_digest.md`.

### Шаг 2 — Анализ трендов

1. Открыть `projects/{product}/memory/signal_log.md` → скопировать последние 4-8 недель.
2. Открыть `projects/{product}/product_brief.md` → скопировать.
3. Открыть `prompts/02_analyze.md` → скопировать промт.
4. Вставить в Perplexity: signal_log + product_brief + промт.
5. Получить ответ → сохранить как `projects/{product}/digests/YYYY-WNN/analysis.md`.

### Шаг 3 — Финальный бриф

1. Открыть `prompts/03_brief.md` → скопировать промт.
2. Вставить в Perplexity: raw_digest + analysis + промт.
3. Получить ответ → дополнить `projects/{product}/digests/YYYY-WNN/analysis.md` или отправить в Telegram/Slack.

### Шаг 4 — Обновить memory

1. Открыть `projects/{product}/memory/signal_log.md`.
2. Добавить новую запись с топ-5 сигналами и статусом гипотез (см. формат в файле).
3. Сохранить в репозитории.

## Время на сессию

| Шаг | Ручная работа | Ожидание LLM |
|-----|--------------|---------------|
| Шаг 1 | ~3 мин | ~2-5 мин |
| Шаг 2 | ~5 мин | ~2-5 мин |
| Шаг 3 | ~3 мин | ~1-3 мин |
| Шаг 4 | ~5 мин | — |
| **Итого** | **~16 мин/нед** | — |

## Несколько продуктов параллельно

Для каждого продукта — отдельная папка в `projects/`. Промты общие.
Шаги 1-4 повторяются независимо для каждого продукта.
